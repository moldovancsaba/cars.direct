# cars.direct

This repository is intentionally empty. cars.direct — a directory of Hungarian car services (repair shops,
tyre services, painters, inspection stations, towing and more) — is an instance of the
[management](https://github.com/moldovancsaba/management) engine, defined there by
`verticals/cars-direct/` and `clients/cars-direct.json`, and served at https://cars.doneisbetter.com.

The previous contents (the retired Cardmass app) remain in this repository's git history.
